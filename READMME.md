# Energy Consumption Prediction Model ⚡

## Overview
This project predicts energy consumption using machine learning based on sensor data such as voltage, current, and temperature.

## Features
- Data preprocessing
- Linear Regression model
- Power consumption prediction
- Visualization using matplotlib

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn

## How to Run

```bash
pip install -r requirements.txt
python main.py
